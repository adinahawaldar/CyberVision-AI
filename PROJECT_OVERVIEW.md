# 🛡️ CyberVision-AI (A-AI) — Complete Project Guide

> **Project Name:** CyberVision-AI / A-AI (Advanced AI Surveillance System)  
> **Target Goal:** Smart City & Government AI Security Surveillance Dashboard  

---

## 💡 What is this Project? (In Simple Words)

Imagine a city or high-security building with **hundreds of CCTV cameras**. Normally, human security guards cannot watch every camera 24/7. 

**CyberVision-AI** is a smart, **AI-powered Web Dashboard** that connects to CCTV cameras and uses **Artificial Intelligence (YOLO Object Detection)** to automatically:
1. **Detect People & Vehicles:** Identifies humans, cars, and suspicious objects in real time.
2. **Spot Dangerous Behaviors:** Flags events like *fall detection*, *crowd formation*, *suspicious movement*, or *unauthorized zone entry*.
3. **Send Instant Alerts:** Notifies security teams with color-coded alerts (High 🔴, Medium 🟡, Low 🟢).
4. **Monitor System Health:** Tracks camera status, network speed, and server health to ensure no camera goes offline unnoticed.

## ⚙️ Tech Stack & Technologies Used

### 🖥️ Frontend (Web Dashboard)
- **Framework:** Next.js 13.5 (React Framework with App Router)
- **Language:** TypeScript (Type-safe JavaScript for clean code)
- **Styling:** Tailwind CSS + PostCSS (Modern responsive layout & sleek dark mode design)
- **UI Components:** Radix UI primitives & Shadcn UI (Buttons, Cards, Dialogs, Toasts, Dropdowns)
- **Icons & Visuals:** Lucide React icons
- **Animations:** Framer Motion & Tailwind Animate
- **Video Streaming:** `hls.js` (HTTP Live Streaming for seamless live CCTV video playback)
- **Data Charts:** Recharts (Interactive graphs for camera uptime, alert trends, and analytics)
- **Forms & Validation:** React Hook Form + Zod (Strict schema validation for login & settings)
- **Real-Time Data:** `socket.io-client` & `axios` (Live notifications and API integration)

### 🧠 Backend & AI Integration (Backend System)
- **AI Engine:** YOLOv8 (Ultralytics) + OpenCV (Real-time object detection and video processing)
- **Backend API:** Python FastAPI / Flask (`http://localhost:8000`)
- **Tracking Engine:** DeepSORT (Real-time person tracking across camera frames)

## 🗂️ Project Structure & Main Features

The dashboard consists of 5 main sections:

### 1. 📊 Main Dashboard (`/dashboard`)
- **Live Metrics Cards:** Displays Total Active Cameras, Active Alerts, System Health, and Bandwidth usage.
- **Recent Alerts Feed:** Live feed of detected security events with severity status.
- **Camera Grid Preview:** View key live camera streams in real-time.

### 2. 🎥 Camera Management (`/dashboard/cameras`)
- **Live Video Streaming:** Multi-camera grid with HLS live playback.
- **Camera Controls:** Add, edit, or remove IP cameras, adjust resolutions, and set GPS locations.
- **Status Indicator:** Shows which cameras are Online 🟢 or Offline 🔴.

### 3. 🤖 AI Assistant (`/dashboard/ai-assistant`)
- An interactive AI chatbot interface to query surveillance logs, ask for camera status updates, or retrieve security incident reports in plain language.

### 4. 🚨 Real-time Notifications (`/dashboard/notifications`)
- Centralized security notification center to view, filter, and acknowledge security alerts generated by the AI detection backend.

### 5. 🏥 System Health (`/dashboard/health`)
- Infrastructure monitoring dashboard tracking CPU load, RAM usage, storage space, and network bandwidth of the surveillance server node.
